TXT → JSON конвертер

Диагностические коды BMW (DTC). Всё выполняется локально в браузере — файлы никуда не отправляются.

Опции
⬆
Перетащите .txt или .json файлы сюда или нажмите, чтобы выбрать
Поддерживаются файлы с массивом [...] или объектом {"codes":[...]}
// пока ничего не загружено
Формат входного текста (нажмите, чтобы раскрыть)

description.en: Problem with the MAF sensor circuit.
description.ru: Проблема с цепью датчика массового расхода воздуха.

models: E46, E90, E60, F10                     ← список через запятую

• блок начинается со строки  === КОД ===

• комментарии: строки, начинающиеся с # или //
• ключи: title., description., solution.,
  models, engines, category, severity, software
